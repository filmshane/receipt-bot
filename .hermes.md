# Hermes — Receipt Bot project rules

Working directory for this product: `/opt/Telegram-Receipt-Analysis-Assistant`

## Hard rules

1. Load and obey `docs/LOGIC_WORKFLOW.md` (primary, no-code build spec) + `AGENTS.md` + `docs/PRODUCT_SPEC.md` + `docs/CODING_WORKFLOW.md` before editing.
2. Do not redesign architecture. Extend within existing layers only.
3. Excel columns in `src/receipt_bot/sheets/headers.py` are frozen.
4. Categories: Travel | Food | Equipment | Other only.
5. Local Excel + Gmail SMTP + Telegram long poll + Grok — no Google Sheets.
6. xAI auth: Hermes OAuth refresh via `src/receipt_bot/llm/xai_oauth.py` (same method as Hermes).
7. Finish only after `./scripts/test.sh` is green.
8. Runtime changes: `sudo systemctl restart receipt-bot` and confirm `active`.
9. Backup `.env` / systemd units as `*.bak-YYYYMMDD` before edits.
10. Never delete `data/expenses.xlsx` or wipe user expense history as a fix.

## Preferred commands

```bash
cd /opt/Telegram-Receipt-Analysis-Assistant
./scripts/test.sh
sudo systemctl restart receipt-bot
systemctl status receipt-bot --no-pager
```
